# QMK autocorrect dictionary — bytemouse Corne
#
# Rules (from docs/features/autocorrect.md and lib/python/qmk/cli/generate/autocorrect_data.py):
#   * Format: "typo -> correction" per line. '#' starts a comment.
#   * Typo charset: a-z and ' (apostrophe). Lowercase only — typos are
#     forced to lowercase by the generator (matching is case-insensitive).
#   * Use ':' to anchor word breaks: ':foo' = after break, 'foo:' = before
#     break, ':foo:' = whole word only. ':' matches space, period, comma,
#     digits, underscore, and most non-alpha. Anchor short or risky entries
#     to prevent mid-word false triggers.
#   * Typo length: warning if <5 chars, hard error if >127 chars.
#   * No typo may be a substring of another in the dict (hard error) — the
#     longer one would never trigger because the shorter fires first.
#   * Correction is sent verbatim via send_string_P → must be ASCII.
#     Umlauts (ä/ö/ü/ß) and other Unicode CANNOT be in corrections.
#   * Holding non-shift modifiers (Ctrl/Alt/AltGr/GUI) resets the buffer,
#     so AltGr-typed German specials like ä/ö/ü/ß also act as word breaks
#     for matching purposes.
#   * Total trie size cap: 64 KB (16-bit node offsets).
#
# Sources for this curated list:
#   * en.wikipedia.org/wiki/Wikipedia:Lists_of_common_misspellings
#   * de.wikipedia.org/wiki/Wikipedia:Liste_von_Tippfehlern
#   * github.com/codespell-project/codespell (programmer dictionary)
#
# Regenerate the C header with:
#   qmk generate-autocorrect-data -kb crkbd/rev1 -km bytemouse autocorrect_dict.txt
# (Or just stage keymap.c — pre-commit hook runs the generator.)
